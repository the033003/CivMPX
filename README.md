# CivMPX

Modern multiplayer extension tooling for Sid Meier's Civilization V.

CivMPX is a clean-room modernization effort inspired by the original MPPatch
project. The goal is to provide lightweight, safe, reversible tooling for
enabling Civilization V mods in multiplayer on native Linux and Windows
running through Proton/Wine.

> Early development — implementation and architecture are not finalized.

## Goals

- Native Linux support.
- Windows + Proton/Wine support.
- Safe and reversible game patching.
- Automatic Civilization V installation detection.
- Game-version detection before patching.
- Patch verification.
- Automatic backups and restoration.
- Lightweight native tooling.
- Minimal external dependencies.
- Clear failure modes.
- No unnecessary modification of the Steam installation.

## Development Status

Currently in the research and reverse-engineering phase.

No patching functionality has been implemented yet.
